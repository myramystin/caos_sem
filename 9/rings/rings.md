```
┌─────────────────────────────────────┐
│           Ring 0 (Kernel)           │  ← Максимальные привилегии
│  ┌─────────────────────────────────┐ │
│  │        Ring 1 (Drivers)         │ │  ← Системные драйверы
│  │  ┌─────────────────────────────┐ │ │
│  │  │     Ring 2 (System)         │ │ │  ← Системные сервисы
│  │  │  ┌─────────────────────────┐ │ │ │
│  │  │  │   Ring 3 (Applications) │ │ │ │  ← Пользовательские приложения
│  │  │  └─────────────────────────┘ │ │ │
│  │  └─────────────────────────────┘ │ │
│  └─────────────────────────────────┘ │
└─────────────────────────────────────┘
```

## Ring 0 (Kernel Mode) - Ядро ОС:

- Полный доступ ко всем ресурсам системы
- Может выполнять любые инструкции процессора
- Управляет памятью, устройствами ввода-вывода
- Обрабатывает прерывания и исключения
- Имеет доступ к привилегированным регистрам (CR0, CR3, MSR)


## Ring 1 и Ring 2 - Промежуточные уровни:

- Изначально предназначались для драйверов устройств
- В современных ОС практически не используются
- Linux и Windows работают в модели Ring 0 + Ring 3

## Ring 3 (User Mode) - Пользовательский режим:

- Ограниченный доступ к ресурсам системы
- Не может выполнять привилегированные инструкции
- Изолирован от других процессов
- Для доступа к системным ресурсам должен использовать системные вызовы
